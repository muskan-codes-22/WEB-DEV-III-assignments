# Web Development III assignments - Lecture 1


## Programs

### calculator.js
A command-line calculator that performs basic math operations.
Run with: `node calculator.js <operation> <num1> <num2>`
Operations: add, sub, multi, div

### dice.js
Simulates rolling a dice 5 times using the crypto module.
Run with: `node dice.js`

### filemanager.js
Demonstrates file operations (create, read, append, delete) using the fs module.
Run with: `node filemanager.js`

### server.js
A simple HTTP server with routes for home, about, and contact pages.
Run with: `node server.js` (runs on port 5000)

### isEven.js and moduleTest.js
A module that checks if a number is even, with a test file.
Run test with: `node moduleTest.js`
